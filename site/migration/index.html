How to run

Both demos from scratch: ./run.sh. The load check as an Airflow Dag, with its environment set up as the README says: airflow dags test load_check.

Made by Andrey Karazhev as a side project about data that moves between systems and quietly stops matching. Contact: hello@minihub.app

The data is fictional. One DuckDB database stands in for both systems; the formats follow the behaviour the README describes. Models: dbt/models/load.
